## 1. Prod estuvo caída (build roto en `main`) — RESUELTO

La web entera daba *"Application error: a client-side exception"* en todas las
páginas (login incluido). **Causa:** se empujaron a `main` commits que **no
compilaban**, y como `next.config` no ignora errores de TypeScript, el deploy del
VPS dejaba un `.next` a medias → ChunkLoadError en todo el sitio.

Errores que rompían el build (ya corregidos):
- `leaflet-draw` importado sin estar resuelto + proyecto `portal-web/` arrastrado
  al type-check (PR **#99**).
- `extractPhoneWithConfidence` no exportada (PR **#99**).
- `?? ` y `||` mezclados sin paréntesis en el portal web (PR **#101**, hotfix).
- Parámetro `d` con `any` implícito en `demo/create-applications` (PR **#108**).

➡️ **Para que esto NO se repita:** ver punto 5.

## 2. Nueva función: ver propiedades archivadas (PR #108)

Antes, la lista `/admin/propiedades` **ocultaba siempre** las propiedades
archivadas (las que se dieron de baja en origen), así que no había forma de
encontrarlas. Ahora hay un botón **"Ver archivadas"** arriba a la derecha
(`?archivadas=1`). Con él activo, el buscador encuentra también las archivadas y
desde su ficha se pueden **reactivar**.

## 3. Seguridad: endpoints de debug cerrados (PR #109)

Tres endpoints estaban **abiertos sin autenticación**:
- `/api/admin/debug-settings` → exponía (parcial) las **API keys** de scraping
  (capsolver/smartproxy). **Borrado.**
- `/api/debug-proxy` y `/api/test-phone-extraction` → disparaban
  Playwright/CapSolver (coste real) sin control. **Protegidos** (solo Owner/Admin).

- **Subida de vídeo .mp4**: bloqueada por el `FILE_SIZE_LIMIT` del contenedor
  `storage` del VPS (~50MB). Subirlo por SSH o usar enlaces YouTube/Vimeo.

## 5. Recomendación clave: proteger `main`

Hoy `main` se rompió **varias veces** por empujar código que no compila
directamente a la rama. El CI ya detecta el build roto, pero no impide mergear/
pushear. **Solución:** activar *branch protection* en `main` (Settings → Branches):
- *Require a pull request before merging.*
- *Require status checks to pass* → check **`check`**.
- *Include administrators.*

Con eso, GitHub **bloquea** que entre a `main` cualquier cosa que no compile. Es
el guardarraíl que evita las caídas de prod.
